# Dots Dungeon
![image](https://github.com/user-attachments/assets/8e2f6ff5-fb83-474d-9621-b072cdf9516f)

## 프로젝트 소개
- 간단한 설명 : 전투를 통해 다양한 스킬을 획득하고, 보스를 빠르게 처치하는 것이 핵심 목표입니다.
- 게임 장르 : 2D 횡스크롤 액션 게임
- 개발 목적 : 영상을 보며 따라 치는 방식이 아닌, 스스로 구현함으로써 실질적인 Unity 개발 능력을 기르는 것.
- [시연 영상 보기](https://www.youtube.com/watch?v=7Kf91ijtl3o)

## 주요 기능
- 주요 기능
    - 액션 카메라 : 선형보간을 활용한 부드러운 카메라 이동 구현
    - 스킬 인벤토리 : 2차원 List을 사용하여 스킬 슬롯 관리 및 스왑 기능 구현
    - 보스 상태 패턴 : 보스 상태 관리 및 전환
    - 데이터 저장 및 불러오기 : Json을 이용한 게임 상태 저장 및 로드 기능 구현
      
## 사용 기술
- Unity 2021.3.32f1 (2D)
- C#
- Git, Github
